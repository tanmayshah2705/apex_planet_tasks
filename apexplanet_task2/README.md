# ApexPlanet Internship — Task 2
## Intermediate HTML, CSS and JavaScript

This project follows Task 2 on page 6 of the ApexPlanet internship PDF.

### Requirements implemented
1. Contact form with text, email and message fields, styled using CSS.
2. JavaScript validation for required fields and email format.
3. Responsive layout using Flexbox for navigation, CSS Grid for content, and media queries.
4. Dynamic to-do list: add tasks, mark complete, and remove tasks using DOM manipulation.

The form is a front-end demonstration only; it does not send or store submitted information. The to-do list intentionally resets on refresh because persistent storage is covered in a later task.

### Run
Open `index.html` in a modern browser. No frameworks or build tools are required.
