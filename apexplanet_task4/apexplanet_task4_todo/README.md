# ApexPlanet Task 4 - To-Do List

A responsive To-Do List application built using HTML, CSS and vanilla JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter All, Active and Completed tasks
- Clear completed tasks
- Display task counts
- Save tasks in browser localStorage so they remain after refreshing or reopening the page

## Run
Open `index.html` in a browser. No installation or backend is required.

Tasks are stored locally in the browser under the key `tanmay-portfolio-tasks-v1`.
