# ApexPlanet Task 4 - Product Listing Page

A responsive product catalogue built using HTML, CSS and vanilla JavaScript.

## Features
- Product cards with name, category, price, rating and description
- Category filtering
- Maximum-price filtering
- Sorting by rating, price and name
- Clear/reset filters
- Responsive layout
- Demo add-button interaction

## Run
Open `index.html` in a browser. No installation or backend is required.

Product information is stored in `js/products.js` as a JavaScript array. Prices and ratings are sample demo data.
