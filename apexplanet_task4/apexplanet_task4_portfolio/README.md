# Tanmay Shah — Personal Portfolio

Responsive multi-page portfolio built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home and selected projects
- `about.html` — Introduction, skills and technologies
- `projects.html` — Project descriptions
- `contact.html` — Contact and social links

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `contact.html` with your public email.
2. Replace the LinkedIn placeholder with your actual profile URL.
3. Add repository/demo links to projects where available.
4. Review all project descriptions before publishing.

## Technologies
HTML5, CSS3, vanilla JavaScript, responsive layouts and Google Fonts.
