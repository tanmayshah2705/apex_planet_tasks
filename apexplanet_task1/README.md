# Task 1 — Basics of Web Development

A simple responsive webpage built with HTML, CSS and JavaScript for the ApexPlanet Web Development internship task.

## Requirements covered

- HTML: headings, paragraphs, an image, navigation links and external resource links.
- CSS: colors, typography, spacing, cards, layout, hover effects and a responsive media query.
- JavaScript: a button click displays an alert message.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a web browser.
3. Click **Say hello** to test the JavaScript interaction.

The Google Fonts import requires an internet connection; the page uses fallback fonts if they are unavailable.
