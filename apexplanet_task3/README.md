# ApexPlanet Internship — Task 3
## Advanced Styling and JavaScript

This project follows Task 3 on page 7 of the ApexPlanet internship PDF.

### Requirements implemented
1. Responsive design using CSS media queries for desktop, tablet and mobile.
2. Interactive quiz with five multiple-choice questions, answer feedback, score tracking, progress indicator, results and restart.
3. Fetch data from a public API using JavaScript Fetch API. The Random Joke Generator uses `https://official-joke-api.appspot.com/random_joke`, displays the setup, reveals the punchline, and handles loading and errors.

### Run
Open `index.html` in a modern browser. No frameworks or build tools are required. An internet connection is required for the joke API.
